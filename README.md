# motion-graphics
موشن جرافيك دعوي — قوالب فيديو مبنية بـ [Remotion](https://www.remotion.dev).

## القالب الأول: `AyahReel`
- مقاس عمودي **1080×1920**، **30fps**، المدة الافتراضية **15 ثانية**
- الآية تظهر **كلمة كلمة** (ظهور مع تلاشي الضبابية وتوهج ذهبي) بخط **Amiri**
- خلفية بزخرفة هندسية إسلامية (نجوم ثمانية) تنزلق بهدوء، ووردة هندسية تدور خلف النص، وذرّات ذهبية
- إطار ذهبي مزدوج يُرسم تدريجيًا، ثم يظهر اسم السورة ورقم الآية في الختام
- الألوان: أخضر زيتي وذهبي (`src/theme.ts`)

الناتج الجاهز: `renders/ayah-reel-ar-raad-28.mp4` (سورة الرعد، الآية ٢٨)

## تغيير النص
عدّل الملف `src/content.ts` فقط:

```ts
export const defaultAyah: AyahProps = {
  intro: "قال الله تعالى",
  verse: "الَّذِينَ آمَنُوا وَتَطْمَئِنُّ ...",   // تُقسَّم بالمسافات: كل كلمة تظهر وحدها
  reference: "سورة الرعد • الآية ٢٨",
  highlightWords: ["اللَّهِ"],                 // كلمات تُلوَّن بالذهبي
  durationInSeconds: 15,                       // التوقيتات كلها تتمدد مع المدة
};
```

- حجم الخط يتكيّف تلقائيًا مع طول الآية.
- يصلح القالب للأحاديث والأذكار أيضًا: غيّر `intro` إلى «قال رسول الله ﷺ» مثلًا.
- أو بدون تعديل الكود، مرّر النص عند الرندر:

```bash
npx remotion render AyahReel out/video.mp4 --props='{"intro":"قال الله تعالى","verse":"إِنَّ مَعَ الْعُسْرِ يُسْرًا","reference":"سورة الشرح • الآية ٦","highlightWords":[],"durationInSeconds":10}'
```

## التشغيل
```bash
npm install
npm run studio     # معاينة وتعديل حي في المتصفح
npm run render     # يُخرج out/ayah-reel.mp4
npm run still      # صورة معاينة لإطار واحد
```
إن لم يجد Remotion متصفحًا فحدّد مسار Chrome/Chromium عبر المتغير `REMOTION_BROWSER`.
